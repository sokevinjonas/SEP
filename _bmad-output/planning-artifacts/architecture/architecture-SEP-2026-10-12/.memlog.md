- (constraint) Single-user Android native mobile app via Capacitor (FR-1..15, solo Jonas).
- (constraint) Frontend local data: IndexedDB is single source of truth (offline-first).
- (constraint) Backend cloud: Cloudflare Worker + Cron Triggers (06:00 & 22:00 Ghana = UTC). Budget summary in KV/D1.
- (constraint) Storage: Captures (photos/screenshots) in Cloudflare R2, immutable/never deleted.
- (constraint) Notifications: Email via Resend on verified domain kgslab.com (no mobile push notifications).
- (constraint) AI integration: Cloudflare Worker holds OpenAI key server-side. App communicates via single secret bearer token (no user accounts). Cost cap ~5 USD/month with automatic cut-off.
- (constraint) Deterministic thresholds (70% advice, 90% warning, 100% overrun); LLM only phrases messages and M. Pognon tone.
- (constraint) UI Design: Calm Ledger, Plum #714B67, Teal #017e84, Amber #ffac00. Logo M. Pognon (coin).
- (event) Mode Coaching sélectionné. Livrable unique: ARCHITECTURE-SPINE.md (build substrate).
- (decision) AD-1 Frontend: Ionic Framework avec Angular et Capacitor (standalone components, TypeScript). Binds: mobile UI components and routing. Prevents: multi-framework drift.
- (decision) AD-2 Local Persistence: IndexedDB via le wrapper 'idb' de Jake Archibald comme source de vérité unique hors-ligne. Binds: local schemas and store access. Prevents: reliance on heavy ORMs.
- (decision) AD-3 Cloud Database: Cloudflare D1 (SQLite distribué) pour la copie miroir des dépenses et le calcul des synthèses de budget. Binds: server-side queries for cron emails.
- (decision) AD-4 AI Model: OpenAI gpt-4o-mini hébergé côté Cloudflare Worker pour l'OCR multimodal et les réponses de M. Pognon. Binds: token spend control within the 5 USD/month cap.
- (decision) AD-5 Sync Protocol: Event-driven local-first queue. IndexedDB commits first with syncStatus='pending', triggers immediate POST /api/sync if online. If offline, Network listener rejoue la file FIFO. Prevents: blocking user operations and sync conflicts.
- (decision) AD-6 Capture & R2 Storage: POST multipart/form-data to Worker /api/captures with bearer token. Worker streams directly to R2 bucket, sends image buffer/URL to OpenAI gpt-4o-mini vision, stores Capture metadata in D1, and returns extracted JSON preview. Prevents: client-side exposure of R2 credentials.
- (decision) AD-7 LLM Context & Privacy: Chatbot context is strictly an aggregated budget summary (month total, daily left, category % and last 5 purchases status) generated server-side. Never send full raw transaction history by default. Prevents: token budget explosion and privacy leak.
- (decision) AD-8 Security & Auth: Single shared static bearer token in Worker env secret, injected into app build config. No user auth tables, no public endpoints without bearer header validation. Prevents: complex auth overhead on a solo-user hobby project.
