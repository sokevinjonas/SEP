# Security Policy 🔒

## Supported Versions

We provide security patches and updates for the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within Student Savings:

1. **Do not disclose the issue publicly** on GitHub issues, pull requests, or public forums.
2. Please report vulnerabilities directly to the maintainers via private GitHub security advisories or by emailing security concerns to the maintainer.
3. Include details of the vulnerability, steps to reproduce, and any proposed fixes if available.

We appreciate your effort in keeping students' financial records and credentials safe!
